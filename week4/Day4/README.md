# Week 4 - Day 4: Performance Tuning

## Objective

The objective of Day 4 is to evaluate the performance of the
windowing functionality developed in previous weeks.

## Features Tested

- Tumbling Window
- Hopping Window
- Sliding Window

## Performance Approach

The execution time of each windowing function is measured using
Python's time.perf_counter().

A larger input dataset is used to observe the performance of
each windowing implementation.

## Expected Result

All windowing functions should execute successfully with
acceptable execution time without changing their existing behavior.
