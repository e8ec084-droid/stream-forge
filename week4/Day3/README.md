# Week 4 - Day 3: Regression Testing

## Objective

The objective of Day 3 is to perform regression testing
for the windowing functionality developed in previous weeks.

## Features Tested

- Tumbling Window
- Hopping Window
- Sliding Window
- Empty input handling
- Invalid window size handling

## Testing Approach

Pytest is used to verify that existing windowing functionality
continues to work correctly after recent changes.

## Expected Result

All regression tests should pass successfully without breaking
the existing windowing functionality.
