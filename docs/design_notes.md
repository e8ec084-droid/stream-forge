# Design Notes

### Task
Style baseline dashboard theme.

### Objective
Create a clean and consistent dashboard theme for the React Flow application.

- Ensure enough spacing between UI components.

- Sidebar
- React Flow Canvas
- Node Cards
- Control Panel
