# Week 2 - Day 2

## Hopping Window Grouping

### Objective
Process truck temperature events using hopping windows and calculate the average temperature for each window.

### Technologies
- Python 3.11

### Input
Truck temperature events with timestamps.

### Output
- Create overlapping (hopping) windows
- Calculate average temperature for each window

### Sample Output

Window 1
Temperatures: [34, 35, 36]
Average Temperature: 35.00

Window 2
Temperatures: [35, 36, 37]
Average Temperature: 36.00

Window 3
Temperatures: [36, 37, 38]
Average Temperature: 37.00
