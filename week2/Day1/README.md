# Week 2 - Day 1
## Tumbling Window Grouping by Timestamp

### Objective
Implement tumbling window grouping for truck temperature events using timestamps.

### Technologies
- Python 3.11

### Input
Truck temperature events with timestamps.

### Output
- Group events by timestamp
- Calculate average temperature for each window

### Sample Output
Window: 10:00
Temperatures: [34, 35]
Average Temperature: 34.50

Window: 10:01
Temperatures: [36, 37]
Average Temperature: 36.50

Window: 10:02
Temperatures: [38]
Average Temperature: 38.00
