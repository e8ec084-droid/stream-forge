# Week 2 - Day 5

## Windowing Integration into Streaming Topology

### Objective
Integrate sliding window logic into a simple streaming pipeline and calculate the average temperature for each window.

### Technologies
- Python 3.11

### Input
Temperature values:
[34, 35, 36, 37, 38]

### Output
- Read streaming data
- Apply sliding window
- Calculate average temperature
- Display each window and its average

### Sample Output

Streaming Started...

Window 1
Temperatures: [34, 35, 36]
Average Temperature: 35.00

Window 2
Temperatures: [35, 36, 37]
Average Temperature: 36.00

Window 3
Temperatures: [36, 37, 38]
Average Temperature: 37.00
